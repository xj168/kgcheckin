## 酷狗签到仓库增加 GitHub Actions 保活

- 背景：仓库 `xj168/kgcheckin`（酷狗概念 VIP 自动签到 fork），GitHub 会停用「连续 60 天无提交」仓库上的所有 schedule 定时任务，导致 `main.yml` 每日签到被自动停止。
- 新增 `.github/workflows/keepalive.yml`：
  - `cron: '17 3 1 * *'`（每月 1 号 03:17 UTC / 北京 11:17）
  - `permissions: contents: write` + `concurrency: keepalive`
  - checkout 使用 `secrets.PAT || secrets.GITHUB_TOKEN`（PAT 优先）
  - 有 PAT 时通过 `gh api` 列出 workflows，对 `state != active` 的执行 `PUT .../enable` 自动重新启用
  - 追加时间戳到 `.keepalive/history.txt`（保留最近 24 行），提交信息带 `[skip ci]`
  - 时间戳用 `date -u -d '+8 hours'` 而非 `TZ=Asia/Shanghai`（本地 Git Bash tzdata 缺失，TZ 不生效）
- README 增加「启用 Actions keepalive」小节说明。
- 注意：已被停用（Disabled）的仓库无法靠 workflow 自救，必须先手动点一次 Enable。
- 遗留：README 写「每天北京时间 00:01 签到」，但 `main.yml` 实际 cron 是 `1 23 * * *`（北京 07:01），文档与实现不一致，未擅自修改。
